Node.js не найден на этом компьютере.

Можно скачать автоматически: ответь Y на вопрос выше.
  - Скачается LTS-версия (~30 МБ) с nodejs.org
  - Распакуется в папку 'node' внутри проекта
  - В систему ничего не устанавливается, PATH меняется только для этого окна

Если auto-download не сработал, поставь Node.js вручную:
  1. Открой https://nodejs.org/
  2. Скачай версию LTS и установи (можно всё по умолчанию)
  3. Закрой это окно и запусти start-bot.bat снова

npm ставится вместе с Node.js — отдельно ставить не нужно.
